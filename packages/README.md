# VANTOR packages

The Minimal base package is responsible for every command required to boot, inspect, administer, repair and install VANTOR. Do not split essential VANTOR control tools into optional packages.

## Package policy

- **Bundled:** included in the installed base system or BusyBox.
- **Building:** source/build integration is underway; not installable or promised preinstalled until the binary is actually in the base payload and tested.
- **Planned:** optional future Nyan package; not installable yet.

The core command set includes `vantorctl`, `vantor-hw`, `vantor-network`, `vantor-storage`, `vantor-service`, `vantor-modules`, `vantor-install`, Nyan and BusyBox `vi`.

The wheel sudoers policy is generated by the rootfs builder, but the `sudo` executable is not yet included. The sudo package must be built for each supported CPU baseline and integrated into the base image before changing its catalog status to `bundled`.

`nano` and full `vim` are optional editor packages. BusyBox `vi` remains available in Minimal so the system can be edited and repaired without downloading anything.

Each package recipe must pin its source version, URL, checksum, build instructions, installed files, and license information.
