VANTOR Linux — Minimal Profile 0.1.0

Primary edition: VANTOR Minimal.

This profile installs the first bootable-oriented minimal userspace payload:
- VANTOR Base Files: OS identity, init scripts, root and live account database, wheel policy, Nyan, VANTOR Control, VANTOR Hardware and the TUI installer.
- Static BusyBox: shell, core command applets and the vi editor applet.

Account policy:
- root (UID 0): administrative account; password is locked in the initial image.
- live (UID 1000): standard Live-session account; password is locked in the initial image.
- wheel: administrative group for sudo policy when the sudo package is installed.
- /etc/sudoers.d/10-wheel grants sudo rights to wheel members. The sudo executable is a separate package and is not included yet.

Not included yet:
- sudo executable
- nano and full Vim
- Fastfetch
- network manager and DHCP client
- partitioning and bootloader installation workflow
- graphical desktop

The installer never formats or partitions disks. The destination filesystem must be mounted separately.
