# VANTOR branding assets

The official visual identity is defined in `theme.json` and `theme.css`.

Use `vantor-mark.svg` for compact surfaces and `vantor-lockup.svg` when the full name and slogan fit. Keep copies in their original proportions. The SVG files are source assets; export PNG variants only for systems that cannot render SVG.

System integrations should consume the shared tokens rather than creating independent color palettes. See [the brand guide](../../docs/branding.md).
