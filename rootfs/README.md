# VANTOR root filesystem

The first root filesystem stage is generated by \`tools/prepare-rootfs.py\`.

Run:

\`\`\`sh
make rootfs
\`\`\`

Generated files are written to \`build/work/rootfs\`, not committed into this source directory. See [Genesis rootfs documentation](../docs/rootfs-genesis.md).

This is currently a skeleton. BusyBox, the kernel, libraries, device support and a complete initramfs still need to be integrated before VANTOR can boot.
