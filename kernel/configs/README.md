# VANTOR kernel configuration

The first configuration is generated from upstream x86_64_defconfig and then enables the drivers needed for a small QEMU/Limbo PC:

- initramfs and early userspace support
- devtmpfs, procfs, sysfs and tmpfs
- VGA/VT and 8250 serial console
- PCI and VirtIO PCI, block, network and console
- common emulated PC storage and network devices
- ext4, ISO9660 and basic FAT partition support
- USB host controllers and USB storage

The build script writes the resolved configuration to kernel/configs/vantor-x86_64.config after olddefconfig. That generated file is the exact configuration used for that kernel source version.

The first target is a QEMU-compatible virtual PC. Hardware drivers for physical laptops, Wi-Fi chipsets, GPUs and ARM devices are not implied by this baseline.


## i486 Legacy configuration

The separate legacy builder uses Linux 6.1.193 and writes the resolved configuration to `kernel/configs/vantor-i486.config`. It selects the 486SX CPU family with kernel math emulation, and enables ISA/EISA, floppy, legacy IDE, serial/VGA console, NE2000 and 3Com 3c509 support. This configuration is generated by `make kernel-legacy`; it is not checked into the repository until a successful build has produced and validated it.

## Genesis graphical boot support

The x86_64 kernel build also enables fbdev, VESA/EFI framebuffer support,
Bochs and VirtIO virtual-GPU drivers, simple DRM and DRM fbdev emulation.
These provide candidate framebuffer paths for the native VANTOR Genesis
splash renderer. Availability of `/dev/fb0` still depends on the active
firmware mode and virtual display device; the initramfs automatically falls
back to the ANSI text splash when no supported true-colour framebuffer exists.
The i486 Legacy image intentionally stays text-only.
